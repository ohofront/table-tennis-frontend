# 탁구 경기 결과 기록 관리 시스템 — 프론트엔드 확장 기능 개발 명세서 (1~5차 로드맵)

> 이 문서는 `02_프론트엔드_개발명세서.md`(기본 화면: 홈/선수관리/경기등록/세트입력/경기상세/랭킹/대회/게시판/인증)를 **확장**하는 명세서입니다.
> 기술 스택(Next.js 14 + TypeScript + Tailwind + React Query)과 API 연동 방식은 기존 문서를 그대로 따릅니다.
> API 스펙은 `03_백엔드_확장기능_개발명세서.md`와 1:1로 대응됩니다.
> **중요**: 새 화면을 구현하기 전에 반드시 실제 배포된 백엔드의 OpenAPI 스펙(`/v3/api-docs`)을 확인하고 필드명/구조를 맞추세요 (AGENTS.md 규칙 참고).

## 1차: 대회 접수 관리 + 팀(Team) 화면

### 1.1 대회 목록/상세 — 접수 상태 표시 (기존 화면 확장)

`/tournaments`, `/tournaments/[year]/[id]` 화면에 아래 요소 추가:

| 요소 | 설명 |
|---|---|
| 접수 상태 뱃지 | "접수중 D-3", "마감임박", "마감" 등을 `StatusBadge` 컴포넌트로 표시 |
| 정원 표시 | "12/20팀 접수" 형태의 진행률 바 |

**사용 API**: `GET /api/v1/tournaments/{year}/{id}` 응답에 `capacity`, `registrationEnd`, `isClosed` 필드 포함되어 있다고 가정하고 프론트에서 D-day/뱃지 계산.

### 1.2 팀 목록 (`/teams`)

```
+------------------------------------------------------------+
|                        팀 찾기/관리                         |
+------------------------------------------------------------+
| [🔍 팀명 검색]   [구분: 전체/동호회/회사/공공기관 ▼]  [+ 팀 만들기] |
+------------------------------------------------------------+
| 팀명          | 구분   | 팀원수 | 팀장   | 상세보기 |
|---------------|--------|--------|--------|----------|
| 포항 스매셔즈 | 동호회 | 12명   | 김철수 | [보기]   |
+------------------------------------------------------------+
```
**사용 API**: `GET /api/v1/teams?keyword=&type=`

### 1.3 팀 생성 (`/teams/new`)

| 필드 | 타입 | 검증 |
|---|---|---|
| teamName | text | 필수, 50자 이내 |
| teamType | select | CLUB/COMPANY/PUBLIC |
| description | textarea | 선택, 500자 이내 |
| logoImage | 파일 업로드 | 선택 |

**사용 API**: `POST /api/v1/teams` → 성공 시 `/teams/{teamId}`로 이동

### 1.4 팀 상세 (`/teams/[teamId]`)

```
+------------------------------------------------------------+
|  포항 스매셔즈 (동호회)                    [팀 정보 수정]   |
+------------------------------------------------------------+
| 팀장: 김철수                                                |
+------------------------------------------------------------+
| 팀원 목록                                    [+ 팀원 초대]  |
|--------------------------------------------------------------|
| 이름   | 역할    | 가입일     | 관리        |
| 김철수 | 팀장    | 2026-01-01 |             |
| 이영희 | 팀원    | 2026-02-01 | [제외] [팀장위임] |
+------------------------------------------------------------+
| 이 팀이 참가한 대회                                          |
|--------------------------------------------------------------|
| 2026 상반기 리그전 - 접수완료(승인)                          |
+------------------------------------------------------------+
```

**사용 API**
- `GET /api/v1/teams/{teamId}`
- `POST /api/v1/teams/{teamId}/members`
- `DELETE /api/v1/teams/{teamId}/members/{userId}`
- `PUT /api/v1/teams/{teamId}/captain`

**권한 처리**: `AdminOnly` 컴포넌트를 확장한 `CaptainOnly` 컴포넌트로 "팀원 초대/제외/팀장위임" 버튼을 팀장 또는 ADMIN에게만 노출.

### 1.5 대회 상세 — "참가팀" 탭 추가

기존 `/tournaments/[year]/[id]` 탭 구성에 아래 탭 추가: `[개요] [참가선수] [참가팀] [조편성] [대진표/결과]`

- 참가팀 탭: 접수한 팀 목록 + 접수 상태(대기/승인/거절), ADMIN은 승인/거절 버튼 노출
- "우리 팀으로 접수하기" 버튼 → 본인이 CAPTAIN인 팀 목록에서 선택 + 로스터(출전 선수) 다중 선택 모달

**사용 API**
- `GET /api/v1/tournaments/{year}/{id}/teams`
- `POST /api/v1/tournaments/{year}/{id}/teams`
- `PUT /api/v1/tournaments/{year}/{id}/teams/{registrationId}`

## 2차: 부문별 타이틀 · 시즌 추이 · 자동 대진표

### 2.1 홈 대시보드 확장

기존 "상위 랭킹 선수" 카드 옆/아래에 부문별 타이틀 카드 추가:

```
+------------------------------------------------------------+
| 🏆 이달의 타이틀                                            |
|--------------------------------------------------------------|
| 승률왕: 이영희 (82%)  |  최다경기왕: 김철수 (50경기)          |
+------------------------------------------------------------+
```
**사용 API**: `GET /api/v1/rankings/titles?period=month`

### 2.2 선수 상세 — 시즌 추이 그래프

`/players/[userId]` 화면에 recharts `LineChart`로 월별 승률/평균득점 추이 추가.

```
+------------------------------------------------------------+
| 성적 추이           [월별 ▼] [최근 6개월 ▼]                |
|--------------------------------------------------------------|
|     승률(%)                                                  |
| 100 ┤                                                        |
|  75 ┤      ●───●                                             |
|  50 ┤  ●──●                                                  |
|     └────────────────────────────                            |
|      1월  2월  3월  4월  5월  6월                            |
+------------------------------------------------------------+
```
**사용 API**: `GET /api/v1/players/{userId}/stats/history?groupBy=month&from=&to=`

### 2.3 조편성 화면 — 자동 배정 버튼

`/competitions/[competitionId]/groups` 화면에 "자동 조편성" 버튼 추가.

```
[조 개수: 4 ▼]  [랭킹 기준 시드 배정 ☑]  [자동 조편성 실행]
```

클릭 시 확인 모달("기존 조편성이 있다면 덮어씁니다") → `POST /competitions/{id}/groups/auto-assign` 호출 → 결과를 조별 카드로 렌더링.

## 3차: 클럽 일정 · 출석체크

### 3.1 팀 일정 (`/teams/[teamId]/schedule`)

```
+------------------------------------------------------------+
|  포항 스매셔즈 - 모임 일정                 [+ 일정 등록]    |
+------------------------------------------------------------+
| 화요일 정기연습  2026-09-15 19:00  포항체육관               |
|  참석 현황: 참 8 / 불참 2 / 미정 2         [내 참석여부: ▼] |
+------------------------------------------------------------+
```

**구성 요소**
- 일정 목록 (날짜순)
- 각 일정 클릭 시 참석자 명단 펼침
- 본인 참석 여부를 드롭다운(참/불참/미정)으로 즉시 변경 가능 (낙관적 업데이트)

**사용 API**
- `GET /api/v1/teams/{teamId}/schedules`
- `POST /api/v1/teams/{teamId}/schedules`
- `GET /api/v1/schedules/{scheduleId}/attendance`
- `PUT /api/v1/schedules/{scheduleId}/attendance`

## 4차: 구인구직 · 중고장터 게시판

### 4.1 게시판 탭 구조 (기존 `/boards` 확장)

```
[ 자유게시판 | 구인구직 | 중고장터 ]
```
탭 클릭 시 `GET /api/v1/boards?boardType=FREE|RECRUIT|MARKET` 호출.

### 4.2 중고장터 게시글 카드

```
+------------------------------------------------------------+
|  [썸네일]  버터플라이 라켓 팝니다        판매중              |
|            50,000원                                          |
|            서울 강남구 · 3일 전                               |
+------------------------------------------------------------+
```

**작성 폼 추가 필드** (MARKET 타입일 때만 노출)
| 필드 | 타입 |
|---|---|
| price | number |
| region | text |
| tradeStatus | select (기본값 SELLING) |

**사용 API**
- `POST /api/v1/boards` (boardType, price, region 포함)
- `PUT /api/v1/boards/{boardId}/trade-status`

### 4.3 구인구직 게시글

```
+------------------------------------------------------------+
|  [모집] 화요일 저녁 정기 멤버 구합니다                       |
|  서울 강남구 · 초급환영 · 2일 전                             |
+------------------------------------------------------------+
```
일반 게시글과 동일한 폼이지만 `boardType=RECRUIT`, `region` 필드 활용.

## 5차: 제휴 상품 샵 · 유니폼 제작 문의

### 5.1 샵 목록 (`/shop`)

```
+------------------------------------------------------------+
|  탁구용품 샵                [카테고리: 전체/라켓/러버/신발 ▼] |
+------------------------------------------------------------+
| [상품카드] 버터플라이 티모볼 ALC   79,000원   [외부몰에서 보기 ↗] |
| [상품카드] ...                                                |
+------------------------------------------------------------+
| 팀 유니폼 제작이 필요하신가요?           [유니폼 제작 문의하기] |
+------------------------------------------------------------+
```

**중요**: "외부몰에서 보기" 클릭 시 `product.externalUrl`로 **새 탭 이동**(`target="_blank"`). 사이트 내에서 결제를 진행하지 않습니다.

**사용 API**: `GET /api/v1/shop/products?category=`

### 5.2 유니폼 제작 문의 (`/shop/uniform-request`)

| 필드 | 타입 | 검증 |
|---|---|---|
| teamId | select (내가 속한 팀 목록, 선택) | optional |
| quantity | number | 필수, 1 이상 |
| designNotes | textarea | 선택 |
| contactPhone | text | 필수 |

제출 후 "담당자가 확인 후 연락드립니다" 안내 메시지 표시 (실시간 견적/결제 아님).

**사용 API**: `POST /api/v1/shop/uniform-requests`

### 5.3 관리자 — 문의 관리 화면 (`/admin/uniform-requests`, ADMIN 전용)

```
+------------------------------------------------------------+
| 요청자 | 팀      | 수량 | 상태        | 관리          |
|--------|---------|------|-------------|---------------|
| 김철수 | 스매셔즈 | 15   | 신규        | [상태변경 ▼]  |
+------------------------------------------------------------+
```
**사용 API**: `GET /api/v1/shop/uniform-requests`, `PUT /api/v1/shop/uniform-requests/{id}`

## 8. Codex 작업 지시 예시

```
현재 프로젝트는 02_프론트엔드_개발명세서.md 기준으로 이미 구현되어 있어.

   조편성 화면에 자동 조편성 버튼 추가.
3) 3차: /teams/[teamId]/schedule 구현 (일정 등록, 참석 여부 체크)
4) 4차: 게시판에 자유/구인구직/중고장터 탭 추가, 중고장터 작성폼에 가격/거래상태 필드 추가

각 차수 작업 전에 관련 API의 실제 스펙을 OpenAPI 문서에서 확인하고,
차수별 완료 후 어떤 파일을 만들었는지 요약해줘.
```
